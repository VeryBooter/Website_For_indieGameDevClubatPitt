# Club logo assets

- `club-logo-original.webp`: original logo supplied by the user.
- `club-logo.svg`: manual vector approximation using editable paths and circles, preserving the black square, white gamepad, four colored buttons, and IGD letters. It is a redraw, not a pixel-exact trace.
- `../favicon.svg`: same SVG for the browser tab icon.

The original raster remains available for exact reproduction or comparison.
